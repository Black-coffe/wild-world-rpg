# Конституция UI/UX админки Wild World — «Quiet Premium»

> **Статус:** 🟡 ЧЕРНОВИК НА РЕВЬЮ (2026-06-15). После «ок» владельца становится конституционным правилом в `CLAUDE.md` + ADR-128 в `mmorpg-vault/decisions/`.
> **Превью-эталон:** `public/admin-redesign-preview.html` (открыть `/admin-redesign-preview.html`) — дашборд + полный UI-kit.
> **Дизайн-система (код):** `public/assets/css/admin-ui.css`.
> **Скиллы-источники:** Readiness Fund Style (Jony Ive + топ-VC) · frontend-design (анти-AI-slop).

---

## 1. Зачем это

Текущая админка — сток Hyper (Bootstrap 5) + 8 разноцветных градиентных KPI-карточек + мягкие drop-shadow. Это «дешёвый AI-admin»-вид: ни одного фирменного решения, цвет несёт нагрузку вместо типографики, рябит. `frontend-design` прямо называет анти-паттернами ровно то, что у нас есть: *purple gradients on white*, generic-шрифты, предсказуемые паттерны.

Цель — **один язык**: токены, типографика, компоненты, движение. Чтобы каждую новую страницу админки собирать из готовых блоков, а не верстать заново; чтобы всё выглядело как один дорогой продукт.

## 2. Философия (north star)

Синтез двух скиллов:

- **Less but better** (Dieter Rams → Jony Ive): меньше элементов, у каждого назначение.
- **Типографика — главный герой иерархии**, не цвет (Readiness Fund). Размер и вес ведут глаз; цвет — почти только акцент и семантика.
- **Data first, ornament never** (Tufte): высокий data-ink ratio, никаких декоративных градиентов и chartjunk.
- **Distinctive, не generic** (frontend-design): фирменная пара шрифтов, одна запоминающаяся деталь.
- **Лакмус:** должно читаться как *«спокойно и уверенно, как страница продукта Apple»*, а не *«ярко и современно»*. Если получилось ярко — переделать.

**Подпись системы (то, что запоминается):** тёплая бумага + hairline-границы + чернильный текст + ОДИН янтарный акцент, а числовые показатели набраны крупным **Fraunces** (сериф) с янтарной чёрточкой под значением. Метрика выглядит как строка из инвест-мемо, а не как кислотный градиент.

## 3. Палитра

Брендовый акцент взят из публичного сайта (ADR-062): **amber `#E89B2E`** («фонарь, газовый огонь»). Всё остальное — тёплый монохром. Цвет = акцент + семантика, и только.

| Роль | Токен | Light | Назначение |
|---|---|---|---|
| Чернила | `--ink` | `#1A1714` | основной текст, заголовки |
| Чернила dim | `--ink-3` | `#6B6358` | подписи, вторичный текст |
| Бумага | `--paper` | `#FBFAF8` | фон приложения (тёплый) |
| Поверхность | `--surface` | `#FFFFFF` | карточки |
| Поверхность 2 | `--surface-2` | `#F5F2EC` | инпуты, hover, elevated |
| Линия | `--line` | `#E7E2D9` | hairline-границы |
| **Акцент** | `--accent` | **`#E89B2E`** | единственный бренд-цвет |
| Успех | `--success` | `#4F7A2E` | статус (приглушён) |
| Предупреждение | `--warning` | `#BC8A1E` | статус |
| Опасность | `--danger` | `#B23A2A` | статус, destructive |
| Инфо | `--info` | `#3E6E8E` | статус (dormant и т.п.) |

Тёмная тема — флип тех же токенов (`[data-theme="dark"]`), акцент тот же. Дата-виз — землистая палитра `--viz-1..8`, ведущий цвет amber.

## 4. Типографика

| Назначение | Шрифт | Почему |
|---|---|---|
| Display, заголовки, **числа KPI** | **Fraunces** (вариативный сериф) | характерный, «премиально-редакционный», даёт запоминающуюся деталь; tabular-nums для метрик |
| Body, UI, таблицы, формы | **Hanken Grotesk** | чистый грос­теск, не Inter/Roboto, отлично читается в плотных данных |
| ID, JSON, `setting_key`, код | **JetBrains Mono** | моноширинный, связь с публичным сайтом |

Иерархия — через размер/вес (`.aui-display`, `.aui-h1/2/3`, `.aui-eyebrow`), не через цвет. Полный список — в `admin-ui.css` §4 и в UI-kit.

## 5. Радиусы, тени, движение

- **Радиусы:** середина между флэт-0 (сайт) и мягким — `2 / 4 / 6px` (решение владельца 2026-06-15). Не «обрубленный» флэт, но строго и технично, без «пузатых» углов.
- **Тени:** только микро (`--shadow-1/2`). Никаких глубоких drop-shadow. Глубину даёт hairline-граница, не тень.
- **Движение:** сдержанное, `130–380ms`, `cubic-bezier(.2,.7,.2,1)`. Одна аккуратная волна появления KPI на загрузке (`.aui-rise`, staggered). Hover = подъём на 1–2px / затемнение границы / янтарное подчёркивание. Уважать `prefers-reduced-motion`.

## 7. Правила (что можно / нельзя)

🔴 **Нельзя:**
- Цвет вне токенов (никаких inline `#hex`, кроме дата-данных).
- Градиентные заливки как носитель смысла (KPI, кнопки, шапки).
- Глубокие тени, `text-shadow`.
- Шрифты вне Fraunces / Hanken Grotesk / JetBrains Mono.
- Новый компонент сразу в production-view минуя UI-kit.
- Цвет как единственный носитель статуса (дублировать текстом/иконкой — a11y).

✅ **Нужно:**
- Любой новый компонент — сначала в `/admin-ui-kit.html`, потом в код (как у публичного сайта).
- Иерархия через типографику, цвет — точечно.
- A11y: `:focus-visible`, `aria-label` на иконочных кнопках, контраст AA.
- Tier-2 visual smoke через MCP Chrome (1440 / 768 / 375) после правок.

## 8. План внедрения (после «ок»)

1. Промоут этого документа: правило в `CLAUDE.md` + ADR-128 в vault + tech-writing нота.
2. `admin-ui.css` → подключить в `_head_common.php`; создать `/admin-ui-kit.html` (living styleguide).
3. Переписать общий шелл (`templates/sidebar.php`, `navbar_custome.php`, `admin/layouts/default.php`, `templates/dashboard.php`) на новый язык; убрать зависимость от Hyper там, где она только мешает.
4. Постранично перевести вьюхи (дашборд → index-страницы → формы → спец-экраны) на `.aui-*`. По одной группе за раз, Tier-2 smoke на каждой.
5. Удалить мёртвый AdminLTE из `public/dist/` и неиспользуемые vendor-CSS.

## 9. Решения владельца (2026-06-15)

- **Радиусы:** середина 2–6px (применено в токенах `--r-*`). Не «обрубленный» флэт, но строго и технично.
- **Логотип — официальный знак проекта: «компас»** (`public/assets/img/wildworld-compass.svg`). Фасеточная роза ветров amber `#E89B2E` + cream `#EBDFC6` на тёмной (ink `#1A1714`) плитке — читается на любом фоне от 16px. Применён ВЕЗДЕ: сайдбар админки, шапка публичного сайта (`.brand .mark`), фавиконы (`favicon.svg` + png 16/32/48/180/192/512 + `favicon.ico`). Единый бренд-знак сайта и админки. Выбран из 5 AI-концептов сравнением в обоих контекстах (`/logo-compare.html`).
- **Тёмная тема:** дальний бэклог (идея, не план). Dark-токены в `admin-ui.css` оставлены на будущее; тумблер в админку сейчас не встраивается.

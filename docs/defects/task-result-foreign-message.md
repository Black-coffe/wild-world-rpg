# Итогом задачи на экран встаёт чужое фоновое сообщение

Веб `/play` заменяет залипший экран законченной задачи её итогом. Связки «итог ↔ задача» от крона нет (общий
`Worker` не трогаем), поэтому итог выбирается среди входящих по времени. В ту же минуту крона новичку приходят и
чужие сообщения — шаг обучающей цепочки, подсказка, титул; без фильтра по типу на экран встаёт, например,
«💧 Первый ресурс в кармане!» вместо итога добычи (порядок, виденный в холодном проходе 2026-10-11).

## Цитаты владельца
- 2026-10-12 · спека web-onboarding, story 02 (переписанная) · выбор итога задачи — «Ты выбрал вариант «веб-сторона» под обещание отсекать чужие сообщения по типу, но в переписанной story 02 такого фильтра нет. Итогом считается просто первое сообщение после задачи.»

## Cause
При переписывании story под выбранный вариант я перенёс окно по времени, но не перенёс условие варианта «чужие
сообщения отсекаю по типу».

## Нельзя
- Выбирать итог задачи только по времени/порядку входящих.
- Задавать сигнатуру чужого типа строкой, не сверенной с построителем отправителя.

## Можно
- Нет итога после отсечения чужих — нейтральный экран «✅ … завершена — итог во входящих 🔔».

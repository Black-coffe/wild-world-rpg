# Длинная статичная справка висит в часто показываемом сообщении

Легенда карты занимала ~80 % текста экрана ходьбы, который показывается на каждый шаг.

## Нельзя
- Держать инлайн статичную легенду, список обозначений или таблицу типов в сообщении, которое видят на каждом шаге.
- Обещать «попап» под длинную справку: `answerCallbackQuery(show_alert)` режется на ~200 символов, наведения у ботов нет.

## Как надо
- Тумблер edit-in-place: кнопка «❓ Легенда» перерисовывает то же сообщение в справку, кнопка «назад» — обратно через существующий in-place-рендер экрана.

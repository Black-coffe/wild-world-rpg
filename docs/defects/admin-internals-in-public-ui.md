# В публичном интерфейсе текст про скрытые, админские или будущие слои

На `/map` появилась строка «Скрыто от публики: игроки, базы фракций… (admin-only, отдельным релизом)». Такой
текст раскрывает, что хранит сервер, даёт игроку обещания из роадмапа и подсказывает имена таблиц.

## Нельзя
- Писать игроку «скрыто», «admin-only», «будет позже», «откроем следующим релизом», имена таблиц и полей, TODO в HTML.
- Рендерить `disabled`-элемент с пояснением «только админу».

## Как надо
- Чего нет для игрока — того нет в разметке: флаг в `GameSettings` выключен, элемент не рендерится.
- `title`, `aria-label`, футеры, подсказки и тексты ошибок — тоже публичный UI.

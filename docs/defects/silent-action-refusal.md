# Действие нельзя выполнить, а игрок не получает причину

Игрок жал «Добыть» с выносливостью 4.2 при пороге ≈5, и ничего не происходило: проверка молча
возвращала `emptyResponse()`, а порог нигде не показывался. Нажал — тишина читается как баг.

## Нельзя
- Отказ в действии через тихий `return` или `Request::emptyResponse()` без сообщения.
- Причина вида «недоступно» / «ошибка».

## Как надо
- Каждая ветка отказа — сообщение с конкретной причиной и путём к условию: «нужно ≈N, у тебя M, восстановится через ~K мин».
- Порог показывать ещё на экране до действия; показанное число и проверка — из одного хелпера.

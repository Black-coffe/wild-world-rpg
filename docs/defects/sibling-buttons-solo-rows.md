# Условные кнопки одного класса стоят каждая в своём ряду

Три раза (Персонаж, экран ходьбы, «Мир») новые условные кнопки — «🗺️ Поход», «🔒 Карго-дрон», «🗺 Обзор» —
добавлялись отдельными `$rows[] = [одна кнопка]`, и владелец каждый раз просил собрать их в строку.

## Нельзя
- Добавлять условную кнопку соло-рядом, когда рядом кнопка того же класса.

## Можно
- Соло: «◀️ Назад» / «✅ Подтвердить», одиночный приоритетный призыв, финальная навигация «↩️ В меню».

## Как надо
- Хвостовые условные кнопки — в аккумулятор `$tail[]`, затем `array_chunk($tail, 2)` в ряды; мерить выход нормализатора клавиатуры.

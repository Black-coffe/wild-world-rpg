# Inline-кнопка дублирует постоянную клавиатуру бота

Под уведомлением о достижении висела inline-кнопка «👤 Персонаж», хотя «Перс» всегда есть в постоянной
reply-клавиатуре. Дубль — шум и ломает связанность кнопок.

## Нельзя
- Добавлять в новое (`sendMessage`) уведомление inline «Перс» / «База» / «Крафт» / «Карта» / «Настройки» как «кнопку назад».

## Можно
- Переход внутри edit-in-place цепочки (ADR-018), где callback перерисовывает то же сообщение в карточку.

## Как надо
- Inline — только контекстные действия этого экрана; терминальное уведомление, у которого следующий шаг — одна из постоянных кнопок, идёт без inline-клавиатуры.

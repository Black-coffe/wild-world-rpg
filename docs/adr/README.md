# ADR живут не здесь

Архитектурные решения этого проекта хранятся в **Obsidian-vault'е соседом репозитория**:

    C:\Projects\mmorpg-vault\decisions\ADR-NNN-<slug>.md

Там их уже 169, с 2026-05 и по сегодня, и второго дома у решений быть не должно — разъехавшиеся
списки ADR это ровно тот дрейф, против которого весь documentation contract и написан.

VULYK по умолчанию складывает ADR в `docs/adr/`. У нас это переопределено: см.
`CLAUDE.vulyk.md` → `## Project bindings`. Каталог оставлен как указатель, чтобы агент, пришедший
сюда по инструкции фреймворка, не создал параллельную нумерацию.

**Как заводить новый ADR:** взять следующий свободный номер в `mmorpg-vault/decisions/`, писать
туда, шаблон — `templates/adr.md` (в этом репозитории) или соседние ADR как образец. Ссылку на
решение положить в `mmorpg-vault/decisions/index.md`.

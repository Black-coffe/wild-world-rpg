## Recon (что было известно до первого вопроса)

Полный отчёт разведки — [`docs/specs/roadmap-100-refactor/report.md`](../specs/roadmap-100-refactor/report.md). Ключевое:

- Прод 26.09 (SELECT): 715 персонажей; L10+ 60 (8.4%); L100+ 7, живых 5; L250+ 2, макс 342; регистраций 1–7/нед; WAU ≈ 25; web-only 0 — источник: прод-срез.
- Код: кланов/групп/аукциона/мастерства/территорий/осад/T4/престижа = 0; M22 ≈ Узлы ADR-137; инфра финала и вайпа готова; уровневые гейты контента кончаются на L50 — источник: аудит кода.

- Следы: причина массовой переразметки L1→L2 (378 персонажей) не выяснена.

## Wave ledgers

- 🎯 Решения: ось = приток; dev-рычаг = web-first Фазы 2–3; публикации — обязательный параллельный поток с метрикой рег/нед; этап II (социалка M) сохраняется, открывается при «веб закрыт И WAU ≥ 100 четыре недели подряд».
- 🅰 Допущения: ✗ веб поднимет конверсию пришедших из РФ (нет замера потерь «сайт → бот»); ✗ публикации вернут объём (было доказано в июне–июле, после — не проверялось).
- ⚠️ Риски: без ритма публикаций веб конвертирует несуществующий поток → вопрос про владельца/ритм публикаций.
- ❓ Открыто: трек ветеранов до порога; финал/вайп; формат плана; долги E; ритм публикаций.
- 🔍 Consistency: Q3 vs Q4 — владелец сам разрешил (порог добавлен).

## Synthesis

**Вердикт.** «100 сессий по уровням» заменяется планом по оси **притока**: главный dev-рычаг — web-first (Фазы 2–3), первичный источник объёма — публикации раз в 2 недели. Параллельно — узкий трек для живой эндгейм-когорты (расширение Узлов ADR-137) и трек долгов, который первым делом чинит метрики. Этапы II (социалка M) и III (эндгейм L) сохраняются, но открываются только по числу: **WAU ≥ 100 четыре недели подряд** после закрытия веба. Проверка оси — событийная: после открытия веб-регистрации и 3 статей ≥ 20 регистраций в неделю, иначе новый гриль.

**Assumption ledger**
- ✗ Веб поднимет конверсию пришедших из РФ — дешёвая проверка: метка/замер «сайт → бот → /start» vs «сайт → /play» после открытия регистрации.
- ✗ Публикации снова дадут объём — проверяется первыми 3 статьями (критерий Q14).
- ✗ Ветераны реально играют в Узлы — SELECT по `boss_engagements` за 30д перед спекой V.
- ✗ Переразметка L1→L2 — баг пересчёта — первая D-спека.

- ✓ Кланов/групп/T4 в коде нет — аудит кода.

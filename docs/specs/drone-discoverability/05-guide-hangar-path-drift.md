# `/guide`: путь к Ангару сверен с кодом

## Goal
Раздел «🤖 Роботы и дроны (Ангар)» в `GuideCatalog` перестаёт врать: кнопка названа так,
как она подписана в игре («🤖 Ангар»), и обещание про 🔒 переписано под фактическое
поведение — ангар открыт тому, у кого техника уже есть, заперт тому, у кого нет ни
мастерской, ни техники.

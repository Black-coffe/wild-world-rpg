# Формат записи вердикта (копировать блок как есть)

Один файл на домен. Первая строка файла — список `mid`, которые этот файл обязан закрыть:

```
<!-- mids: 4294974283 4294974469 4294974508 -->
```

Дальше — по одному блоку на жалобу, в порядке возрастания `mid`:

```
### `4294974469` — 2026-07-21 — Kinder surprise

**Суть:** построил верстак 1 уровня трижды — постройки, у которых он в зависимостях, его не видят.
**Вердикт:** устранено
**Чем доказано:** прогон на testbot ... (наблюдалось: ...) + SELECT по проду ... (0 строк)
**На проде:** коммит `<sha>` → `git tag --contains` → `v0.51.664` ≤ `v0.51.666` — правка в прод-релизе.
**Живой прогон:** не нужен
**Черновик ответа:** Починили: верстак теперь виден постройкам. Зайди *🏠 База → 🏗 Строить* — зависимость подхватится.
**Сомнения:** нет
```

## Вердикт — ровно одно из шести

`устранено` · `исправлено, но не на проде` · `не устранено` · `не баг` · `не воспроизводится` ·
`требует живого прогона`

Ответ в ветку уходит **только** по `устранено`. `исправлено, но не на проде` — это отдельный,
не-отправляемый исход: правка есть в `develop` или в `vulyk/*`, игрок её не видит.

## Поле «На проде» — обязательное у каждого блока

Прод стоит на `v0.51.666` (`RECON.md`). «Нашёл коммит в `develop`» и «игрок это видит» — **разные
утверждения**. Второе доказывается одним из:

- `git tag --contains <sha> | sort -V | head -1` — первый содержащий тег обязан быть **не новее**
  `v0.51.666`. `sort -V` обязателен: лексикографика ставит `0.10.0` выше `0.9.x` и врёт.
- `SELECT` по **проду** (`wildworld-bot@…`, только чтение) — дефектного состояния нет / новое
  поведение видно в данных.
- чтение прод-конфига или `game_settings` на проде — для килсвитчей.

Прогон на preprod-testbot доказывает, что правка **работает**, но не что она **на проде**: у
вердикта `устранено` нужны оба доказательства. Если ближайший тег новее `v0.51.666` или тега нет —
вердикт `исправлено, но не на проде`, и в этом же поле называется, **где лежит** (ветка, спека, тег).

## Правила, которые проверяет `verdict-lint.sh`

- Заголовок блока — ровно `### \`<10 цифр>\` — <дата> — <автор>`.
- Все семь меток присутствуют у каждого блока и **непусты**.
- `**Вердикт:**` — ровно одно из шести значений выше.
- `**Черновик ответа:**` — **одной строкой**; для всего, кроме `устранено`, ровно `—`.
- В черновике **парное** число `*` (Telegram-markdown; непарная звёздочка = 400 и тихая недоставка).
- У блоков с вердиктом `устранено` в `**Чем доказано:**` обязан стоять маркер исполнения
  (`SELECT` · `прогон` · `phpunit` · `вебхук` · `скриншот`), а в `**На проде:**` — маркер прода
  (`v0.51.` · `git tag` · `SELECT` · `прод`). Существование коммита/спеки/ADR — не маркер ни там,
  ни там.

Гейт формальный: он видит форму, а не правду. Правду смотрит ревью.

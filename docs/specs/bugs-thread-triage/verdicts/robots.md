### `4294974471` — 2026-07-21 — Kinder surprise

**Суть:** «зачем нужно количество дронов одного типа больше одного, если это ни на что не влияет?» — подозрение автора подтвердилось.
**Вердикт:** подтверждено, но не дефект кода
**Чем доказано:** прочитан код запуска на проде — `RecceDroneAction::handle()` проверяет только `qty > 0`, расходует ИСКЛЮЧИТЕЛЬНО `durability_count` строки `crafted_items_log` (`$newCharge = max(0, $charge - $drain)`), саму `quantity` не трогает и нигде в формуле заряда/радиуса не использует. Крафт второго дрона того же типа мержится в ТУ ЖЕ строку (`GenericCraftCompletionHandler.php`: `if ($existingLog) { $newQty = $existingLog['quantity'] + $quantityToAdd; ... }` — `durability_count` при мердже не меняется). Значит все копии одного типа делят ОДИН заряд — вторая, третья и т.д. штука физически не добавляют ни запуска, ни ёмкости. SELECT на проде нашёл две живые строки, где это уже так: `character_id=1280` и `character_id=1039`, у обоих `crafted_item_id=121 (DroneScout), quantity=2, durability_count=100` — один заряд на пару дронов, не два.
**На проде:** подтверждено прямым чтением деплоенных файлов `wildworld-bot@…`: `RecceDroneAction.php` (строки с `qty <= 0` / `newCharge = max(...)`) и `GenericCraftCompletionHandler.php` (мердж по `existingLog`) — идентичны файлам в `develop`; плюс живой SELECT `crafted_items_log` с двумя реальными персонажами в этом состоянии прямо сейчас.
**Живой прогон:** не нужен — эффект виден по данным двух реальных персонажей на проде, дополнительный UI-прогон ничего не добавит.
**Черновик ответа:** —
**Сомнения:** это не «не баг с пустой рукой» — находка реальна и стоит внимания владельца: сейчас количество однотипных дронов сверх первого не даёт вообще ничего (ни доп. запуска, ни доп. заряда), при этом рецепт `DroneScout` расходует ресурсы на крафт каждой копии. Балансовое решение (сделать `quantity` резервной ёмкостью, как у роботов-добытчиков, или явно ограничить крафт одним) — не в этой спеке (non-goal: баланс карго/дронов не проектируем), но сама находка выходит за рамки «ответить в чат» и адресована владельцу.

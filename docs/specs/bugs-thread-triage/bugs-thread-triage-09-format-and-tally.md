# Ремонт: седьмой вердикт, воспроизводимый учёт, верная цифра отсечения

## Goal

Три находки ревью, которые живут в служебных файлах спеки и блокируют доверие к остальному:
словарь вердиктов не умеет назвать «жалоба верна, но это не дефект кода»; закрывающий учёт
сообщений не воспроизводится из собственных списков; цифра невыкаченных коммитов завышена в полтора раза.

## Что делать

1. **Седьмой вердикт** (находка MAJOR-5). Сейчас шесть значений, и ни одно не означает
   «жалоба игрока подтверждена фактами, но это не дефект кода — это дизайн или баланс».
   Из-за этого `4294974471` («зачем больше одного дрона») носит ярлык `не баг`, хотя тот же
   блок доказывает: находка реальна, двое живых игроков на проде в этом состоянии.
   Добавь значение **`подтверждено, но не дефект кода`**. Последствие у него то же, что у
   остальных не-`устранено`: **ответа в чат не уходит** (решение владельца на брифинге).
   Меняется только честность ярлыка, не поведение.
2. **`verdict-lint.sh`** — принять седьмое значение; черновик ответа у него по-прежнему обязан
   быть `—`. Прогони скрипт на всех семи файлах вердиктов, убедись, что ничего не сломал.
3. **Учёт (находка MAJOR-6).** Таблица «27 + 45 + 9 = 81» в `plan.md` не воспроизводится:
   в ней названы 48 id, из них два (`4294971813`, `4294974591`) вообще не сообщения ветки,
   пять посчитаны дважды (они же — mid'ы вердиктов), а 13 настоящих сообщений не названы нигде
   в этом разделе (одиннадцать из них названы внутри блоков вердиктов, два — в story).
   Жалоб при этом не потеряно ни одной — проверено ревью. Перепиши раздел так, чтобы **арифметика
   сходилась из тех id, которые он сам перечисляет**, а остаток был назван явно: «учтены внутри
   блоков вердиктов, вот где». Утверждение о полноте обязано быть доказательством, а не заявлением.
4. **Цифра отсечения (находка MINOR-7).** `RECON.md` говорит «60 коммитов мимо прода».
   Их **40**: `git rev-list v0.51.666..develop --count`. Ошибка возникла из-за `git log --since`,
   который считает по дате коммита и захватывает уже вошедшие в тег. Исправь цифру и **назови
   правильную команду** вместо прежней, чтобы следующий раз мерили по предку, а не по времени.
   Сама линия отсечения верна и подтверждена независимо — правится только число и метод.

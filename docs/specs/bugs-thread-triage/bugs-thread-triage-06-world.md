быть» вынесен вердикт из шести по `verdicts/_FORMAT.md` против актуального **прод**-состояния.

## Линия отсечения — прод, а не `develop`

Прод стоит на **`v0.51.666`** (деплой 11.09), в `develop` поверх него 60 невыкаченных коммитов —
`RECON.md`. «Нашёл коммит» и «игрок это видит» — **разные утверждения**. Принадлежность проду:
`git tag --contains <sha> | sort -V | head -1` (тег не новее `v0.51.666`; `sort -V` обязателен),
либо прод-`SELECT`, либо чтение `game_settings` **на проде** — для килсвитчей это единственное
доказательство. Правка есть, но тега нет или он новее → вердикт `исправлено, но не на проде`
+ где лежит. Прод — только чтение (`wildworld-bot@…` = ПРОД, `wildworld-testbot@…` = preprod).

⚠️ Отдельно: **`vulyk/craft-shelf-coverage` (ADR-185) — 27 крафт-предметов без экрана применения,
вывод из обращения + компенсация — не смёржена даже в `develop`** (`RECON.md`). Это прямой ответ
жалобе `4294974537`; вердикт по ней не может быть `устранено` — потолок
`исправлено, но не на проде (и не смёржено)`.

## Гипотезы (проверить, не поверить)

- `4294974544`/`4294974546` ↔ ADR-174 «Система транспорта» (5 машин, темп Похода, килсвитч
  `world.vehicle.enabled`). На момент репорта транспорта действительно не было — владелец сам это
  сказал. Вердикт зависит от **состояния килсвитча на проде** и от того, есть ли у игрока дверь
  к машине: конфиг плюс строки в БД — это ещё не дверь. Килсвитч выключен на проде → честный
  вердикт `не устранено` (или `исправлено, но не на проде`, если код доехал, а тумблер нет);
  в чат по нему не пишем.
- `4294974537` — два разных вопроса: (а) предметы попали к игроку наградой за PvE по ошибке —
  закрыт ли «кран» **на проде** и остались ли артефакты в данных (прод-`SELECT`); (б) игрок не
  понимает назначения целых разделов инвентаря — это ровно то, что закрывает несмёрженная
  `craft-shelf-coverage`, см. предупреждение выше.
- `4294974594` ↔ спека `backpack-teleport-base-choice` (approved 24.08): назначение — выбранная
  игроком активная база, а не первая заклеймленная клетка. Проверять достижимость выбора на
  экране и принадлежность правки прод-тегу, а не наличие сервиса. Смежное:
  `Death/PlayerRespawner.php:82` по-прежнему берёт `claimed_cells` голым `first()` (non-goal той
  спеки) — если всплывёт, это находка, не вердикт.
- `4294974601` — «ордината 0 не отображается»: кандидат в семью «ложь falsy-значения» (0 читается
  как «пусто»). Рендер мира PHPUnit не покрывает (в `wildworld_tests` нет таблицы `map`) —
  доказательство только на реальных данных: `php spark`-команда/маршрут на testbot либо живой
  экран карты через story 07, плюс тег для прода.

## Non-goals

- Не чинить: ни строки в `app/`, ни миграции, ни теста.
- **Не считать коммит в `develop` или ветку `vulyk/*` доказательством «устранено»** — для этого
  есть отдельный вердикт.
- Не заходить в MCP Chrome и Telegram Web — браузер держит story 07.
- Не трогать килсвитчи `GameSettings` ни на проде, ни на testbot: состояние читаем, не флипаем.
- Не выносить вердикт по мульти-базе на карте (`4294974671`) — это `bugs-thread-triage-01`.
- Не обещать в черновиках транспорт, пока он не доказан достижимым для игрока **на проде**.

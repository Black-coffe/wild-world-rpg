## Линия отсечения

| Факт | Значение | Чем проверено |
|---|---|---|
| Прод-релиз | `v0.51.666` | каталог релиза на проде `~/releases/2026-09-10-213619` (серверное UTC) ↔ тег `v0.51.666` от `2026-09-11 00:31 +0300`, коммит `5c956b45`; разрыв 5 минут = деплой этого тега |
| Симлинк прода | `/home/wildworld-bot/releases/2026-09-10-213619` | `readlink -f ~/htdocs/bot.wildworld.fun` |
| Коммитов в `develop` мимо прода | **60** | `git log --since='2026-09-10 21:36' develop` — вся волна `pvp-detection-clarity` от 11.09 |
| Несмёрженная ветка | `vulyk/craft-shelf-coverage` (11.09) | `git branch --contains` показывает только саму ветку |

🔴 **Вердикт `устранено` меряется прод-релизом, а не `develop`.** Правка, лежащая в `develop`
или в `vulyk/*`, для игрока не существует. Проверка принадлежности коммита проду:

```
git tag --contains <sha> | sort -V | head -1     # sort -V обязателен: лексикографика врёт
```

Если ближайший тег старше `v0.51.666` или его нет — это `исправлено, но не на проде`.

## Известные несовпадения кода и прода, задевающие ветку

- **`craft-shelf-coverage` (ADR-185)** — 27 крафт-предметов в 8 типах без экрана применения,
  вывод из обращения + компенсация золотом. Ветка **не смёржена даже в `develop`**.
  Прямо отвечает жалобе Михаила Сорокина от 19.08 («не понимаю назначение предметов…
  волшебные предметы») — вердикт по ней не может быть `устранено`.
- **`pvp-detection-clarity`** — целиком в `develop` и на preprod, ждёт слова владельца.
  На проде нет. Ветку багов почти не задевает, но если вердикт упрётся в PvP — помнить.

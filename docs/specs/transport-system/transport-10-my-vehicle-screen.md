# Экран «🚚 Мой транспорт» + витрина фракционных машин

## Goal

У игрока появляется место, где транспорт живёт: что активно, сколько износа осталось **в клетках**,
строка окупаемости («эта повозка сэкономила тебе 47 минут»), кнопки активации/снятия и витрина
четырёх фракционных машин со честной шапкой «Выбор фракции на 10 уровне решает, какая из этих
машин станет твоей. Навсегда». Экран доступен всем и всегда — в том числе игроку без фракции
и без единой машины.

## Requirements

> То есть должно быть минимум три-четыре вида: один общий для всех фракций и остальные уникальные для разных фракций.

> и персонажа перевозить

## Acceptance criteria
- [ ] Рендер вынесен в чистую функцию (без БД и Telegram), принимающую состояние; весь тест идёт по ней.
- [ ] 🔴 Caption ≤ 1024 символов на самом длинном состоянии (активная машина + пять карточек + витрина) — тест на чистой render-функции, а не заметка.
- [ ] Media-off: текст несёт название, эффект числами, остаток износа в клетках, что нажать — смысла в картинке нет.
- [ ] Витрина рендерится игроку **без фракции** (id 5) и без единой машины: четыре карточки видны, 🔒 объясняет причину и путь («нужна фракция Инженеры», «с 14 уровня — у тебя 11»).
- [ ] Активация чужого `log_id` (подмена callback) → отказ с текстом, без изменения указателя.
- [ ] Повторная активация другой машины переставляет указатель: на экране активна ровно одна.
- [ ] Снятие работает откуда угодно, в том числе не на базе; надевание не требует базы.
- [ ] Указатель на удалённую строку → экран показывает «нет активной машины», не падает.
- [ ] Износ показан **в клетках** («хватит ещё на ~40 клеток»), не в процентах; на нуле — «разбита, нужен ремонт» + кнопка ремонта.
- [ ] Строка окупаемости считается из накопленной экономии и отсутствует, пока экономии нет (не показывать «0 минут»).
- [ ] Зарегистрированы маршруты `vehicleScreen`, `vehicleActivate_<logId>`, `vehicleDeactivate`, `vehicleShowcase`, `vehicleLockInfo` — последний нужен story 12 и обязан существовать после этой story.
- [ ] Вход на экран есть в экране Персонажа и виден **всегда**, даже когда транспорта нет (UX-DISCOVERABILITY: не скрывать вход).

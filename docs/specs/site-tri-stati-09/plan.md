# Три статьи на wildworld.fun: дев-блог, дневник, SEO (plan)

**Tier:** 2 · **Spec slug:** `site-tri-stati-09` · **Brief:** [brief.md](brief.md)
**Governed by:** ADR-062 (flat-stencil, тон), ADR-022 («Найденная фотоплёнка» — обложки), SEO-CONTENT-PLAN-50 (§2 анти-каннибализация, §7 правила), SEO-WEB-ROADMAP (потоки A/B/D), скилл `/redkollegiya` (единственный санкционированный путь публикации)
**Depends on:** волна 1 плана-50 закрыта 10/10 (последние публикации 2026-09-06); `multibase-picker` на проде `v0.51.669`

## Goal

Оживить мёртвый GSC-пайплайн и на его свежих данных выпустить три статьи разных потоков:
дев-блог о выборе базы (поток B), «Дневник выжившего №11» о втором доме (поток A) и одну
поисковую статью (поток D), тема которой выбирается по реальным показам, а не по очерёдности
волн. Ни одна из трёх не должна отнимать интент у наших же 135 страниц.

## Assumptions

- **Grant в GSC даёт владелец, я не могу.** Пайплайн упирается ровно в `User does not have sufficient permission`; всё остальное (ключ, JWT, токен, команда) проверено рабочим 2026-09-16. Пока grant'а нет, работа №3 стоит, а №1 и №2 идут своим ходом.
- **Дев-блог и дневник об одной механике — не каннибализация.** Оба не целятся в поисковый запрос (поток A — нарратив, поток B — низкочастотный сигнал живой игры), разводятся жанром и получают взаимные ссылки. Метки CTA разные, чтобы конверсия считалась раздельно.
- **ADR-186 «окно противостояния» не упоминается ни в одной статье.** На проде killswitch выключен — обещать нельзя (правило анти-дрейфа §7.5).
- **Публикация — только через `/redkollegiya`.** Черновик живёт как `status=draft`, `published` ставится после полного PASS. Максимум два круга правок.
- **У каждой статьи обязательна `featured_image`** (урок 2026-05-31: пост без обложки даёт плейсхолдер «§») и постатейная метка `?start=src_site_*_<slug>` (§7.7).
- **Свежая выгрузка может не перевернуть картину.** Данные 29.07 — 16-месячное окно; если `seo:gsc-pull` за 90 дней даст ту же тройку лидеров, тема №3 берётся из плана-50 без выдумывания новой.

## Stories

**Волна 0 — данные (блокирована владельцем)**

- `02-topic-pick` — сверка среза с §2 плана-50 и каталогом 135 постов → тема статьи №3 + целевой запрос + с чем разводим. **Показывается владельцу до написания.**

**Волна 1 — черновики (идут параллельно, волны 0 не ждут №03 и №04)**
- `03-devblog-base-picker` — дев-блог «выбор базы», поток B, 400–800 слов, CTA `src_site_devblog_*`.
- `04-dnevnik-11-vtoroy-dom` — «Дневник выжившего. Запись одиннадцатая», поток A, сверка стиля с записями 1–10, CTA `src_site_dnevnik_*`.
- `05-seo-article` — статья по теме из `02`, поток D, CTA `src_site_seo_*`. Стартует после `02`.

**Волна 2 — гейт и публикация (последовательно, по одной)**

**Волна 3 — бумага**

## Contracts

- **Формат черновика** (вход `/redkollegiya`): frontmatter `post_title`, `post_slug`, `post_category`, `post_meta_description`, `post_excerpt`, `cta_deeplink`, `cover_scene` + блок `## content_html`. Путь — `C:\Projects\mmorpg-vault\inbox\site-drafts\<slug>.md`.
- **Метки источника:** дев-блог `src_site_devblog_<slug>`, дневник `src_site_dnevnik_<slug>`, SEO `src_site_seo_<slug>`.
- **Взаимные ссылки:** дев-блог ↔ дневник №11 обязательны в обе стороны; дневник №11 получает prev-ссылку на №10 «Хозяин», а №10 — next-ссылку на №11 (правка уже опубликованного поста в CMS, фаза 4 редколлегии).
- **Категории:** дев-блог и дневник — `devblog`; категория SEO-статьи определяется в `02` вместе с темой.

`curl -sS -o /dev/null -w '%{http_code}' https://wildworld.fun/<slug>` → 200 на каждую из трёх.

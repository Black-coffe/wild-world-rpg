# Brief: w-reg-banner-fit

**Date:** 2026-10-26 · **Tier:** 1 · **Track:** хвост W-REG.5 (`v0.51.704`) · **Source:** смоук `docs/specs/w-reg-banner/smoke-preprod.md`, замечание бокового агента

## Request (verbatim)

> Раскрывать, только если влезает (Рекомендую)

Вопрос, на который это ответ:

> На ноутбуке 1440×900 раскрытое новое сообщение оставляет экрану игры ~11 px у нижнего края (уже на проде в v0.51.704). Что делаем?

Описание варианта: JS раскрывает новое сообщение и меряет: если экран игры ушёл ниже ~¾ высоты окна, сворачивает
обратно. Короткое текстовое сообщение на ноутбуке остаётся раскрытым, длинное с фото — нет. На больших мониторах всё как сейчас.

## Asks

1. На ≥768 px самое новое сообщение плашки авто-раскрывается, только если после раскрытия верх экрана игры
   (`#play-state`) не ниже ¾ высоты окна; иначе остаётся свёрнутым. Замер 1440×900 на preprod с длинным новейшим
   сообщением: свёрнуто, экран игры в верхних ¾ окна.
2. Остальное W-REG.5 не меняется: на 375 всё свёрнуто; раскрытое игроком переживает опрос; авто-раскрытие — один раз
   на `message_id`; без JS всё свёрнуто. JS `?v=6`.
3. (вердикты) `/guide` — нет, совет — нет, WipeManifest — не нужен, баланса нет (¾ — порог вёрстки, не баланс).

## Asks

1. Смена пароля в кабинете (`/account/identity/email` для своей уже привязанной почты) требует текущий пароль: без него или с неверным — отказ «Неверный текущий пароль», хэш не меняется. Добавление почты впервые текущего пароля не требует.
2. Страницы сброса пароля (`/account/reset`, `/account/reset/<token>`) не грузят сторонний скрипт аналитики (Statable) и отдают заголовок `Referrer-Policy: no-referrer`: токен из URL не уходит третьим сторонам ни через скрипт, ни через Referer.
3. Вердикты: в /guide не добавляем (не игровая механика); совет не добавляем (защиты аккаунта, не механика).

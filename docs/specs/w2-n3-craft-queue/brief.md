## Answers

1. **Каталог** — Веб нативно, бот как есть: индекс «верстак → категория → рецепты» из CraftRecipes; веб рисует верстаки, категории и одну общую карточку рецепта из него. Старт/очередь/отмена/завершение — общее ядро для обоих. Штучные карточки бота не трогаем.
2. **Атомарность** — Чинить при выносе в ядро: золото и предметы — условной записью, продвижение — только из status='queued', отмена возвращает туда, откуда взяли. Лимиты очереди — в GameSettings.
3. **Количество** — Кнопки + поле числа: те же шаги, что у бота (из CraftCardHelper), плюс поле «своё число» с потолком «сколько хватает сырья» для любого рецепта; бот не меняется.
4. **Требования** — Верно, стоп на плане.

## Asks

1. Крафт — одно ядро для бота и веба: старт, очередь, отмена, завершение и длительность в сервисе; handler'ы бота становятся рендерерами, их сообщения и кнопки — прежние.
2. Индекс «верстак → категория → рецепты» из CraftRecipes; в /play — нативные верстаки с замками и путём к требованию, категории и общая карточка рецепта (сырьё из рюкзака и склада, время, цена, условия); каталог бота не меняется.
3. Количество в веб-карточке — кнопки шагов бота плюс поле «своё число» с потолком по сырью.
4. Очередь в /play рядом с крафтом: активные с живым таймером, ожидающие с позицией и оценкой времени, отмена ожидающих; завершение крафта видно в вебе, в том числе у игрока без Telegram.
5. Атомарность: золото и предметы-ингредиенты — условной записью, продвижение очереди — только из queued, отмена возвращает туда, откуда взяли; лимиты очереди и слотов — в GameSettings.
6. Верстаки, карточка и очередь — сначала в ui-kit.html; без горизонтального скролла на 375/768/1440.
7. Хвосты W2.N2: строка задач не пишет «готово» у идущего Похода; клетка карты на 375 — удобная для пальца.
8. Вердикты: паритет — одно ядро для обоих клиентов; /guide — нет, механика крафта не меняется; совет — нет, совет про игру на сайте уже есть.
9. Живой проход на preprod: веб — верстак, категория, карточка, старт, очередь с таймером, отмена, завершение; бот — хаб, старт, очередь, отмена, завершение после рефакторинга.

# Замок: ни одна карточка крафта не оставляет игрока без выхода

## Goal
Появляется тест, который падает, если карточка крафта не умеет вывести игрока из состояния «нельзя собрать ни одной штуки». Двадцать восьмая карточка не сможет появиться без выхода — именно так этот слой и разъехался.

## Requirements
> для всего абсолютно крафта (ТОЛЬКО КОРАФТ) строения не входят сюда
> Недостаточно ресурсов, чтобы скрафтить хотя бы 1 шт.

# Список обнаружения: по кому бьёшь — видно, а непоказанный сосед не считается показанным

## Goal

После story игрок понимает, по какому соседу он бьёт, ДО нажатия кнопки, а сосед, не попавший в
обрезанный список, не отмечается как уже показанный и не глохнет на следующем шаге.

## Requirements

> BLOCK, major #8: `PlayerDetectionService.php:152-160` пишет строку в `player_detection_history` для КАЖДОГО обнаруженного, и только потом `renderDetectionMessage()` режет список до `max_listed`. На следующем шаге `canSendNotification()` отсекает их по кулдауну пары — 111 из 123 соседей не появятся вовсе, хотя игрок их не видел.

> BLOCK, major #11: в клавиатуре до 12 одинаковых кнопок «⚔️ Атаковать» без имени цели; после упаковки 2–3 в ряд ряды больше не соответствуют строкам 1:1, а «🤺 Дуэль» и хвостовая «🏃 Бежать» сдвигают позиции. Тап — это удар по живому игроку с потерей имущества.

## Acceptance criteria
- [ ] Отметка «показан» ставится только тем соседям, которые реально попали в отправленный игроку текст. Тест: обнаружено больше, чем влезает, — строк в `player_detection_history` ровно столько, сколько показано, и непоказанный сосед появляется на следующем шаге.
- [ ] Метка кнопки атаки несёт имя соседа (или иной признак, однозначно связывающий кнопку со строкой списка), так что игрок видит, по кому бьёт, до нажатия. Кнопки-замки, «🤺 Дуэль» и хвостовая «🏃 Бежать» не должны смещать это соответствие.
- [ ] Имя в метке экранировано и обрезано так, чтобы длинное имя не ломало клавиатуру; кнопок по-прежнему 2–3 в ряд, ни одной одиночной в строке.
- [ ] Потолок списка и бюджет символов держатся как прежде — сообщение не начинает упираться в лимит Telegram. Существующие тесты на потолок остаются зелёными.
- [ ] Смысл полон без картинки (media-off): по одному тексту понятно, кто рядом, какого уровня, кто брошен и почему часть соседей не показана.

## Implementation notes

- BLOCK #8: убран `detectionHistoryModel->insert()` из первичного цикла `detectNearbyPlayers()`
  (там, где кандидат проходит `canSendNotification()`) — теперь только собирает
  `$detectedPlayers`. `renderDetectionMessage()` возвращает третий ключ `shown_ids` (`list<int>`)
  — id соседей, чья строка реально попала в текст ДО обрыва по `$maxListed`/`MAX_TEXT_CHARS`.
  `detectNearbyPlayers()` пишет историю ПОСЛЕ рендера, циклом по `shown_ids`. Непоказанный
  сосед (обрезан по потолку/бюджету) не получает штампа `detected_at` → на следующем шаге
  `canSendNotification()` его не отсечёт, он появится снова.
- BLOCK #11: новый приватный `buttonName(string $rawName, int $id): string` — чистит
  `\r\n\t` в пробел, `trim()`, при пустом имени — `'№' . $id` (тот же fallback, что и у
  текста строки), обрезает до `MAX_BUTTON_NAME_CHARS=20` символов с `…`. Применён во ВСЕХ
  трёх видах кнопок ряда: `⚔️ Атаковать: <имя>`, `🔒 <причина>: <имя>`, `🤺 Дуэль: <имя>` —
  соответствие «кнопка → сосед» видно на самой кнопке независимо от того, как `ButtonPacker`
  расставил ряды и куда попали «🤺 Дуэль»/хвостовая «🏃 Бежать» (она осталась без имени —
  она не про конкретного соседа).
- Не HTML-экранирование (кнопка — plain-text поле Telegram, не подпись сообщения), а
  очистка управляющих символов + обрезка длины — то, что реально может сломать вид клавиатуры.
- Существующие тесты `testLockInsteadOfAttackWhenPvPRestrictionDeniesByLevel` и
  `testAllowedNeighborGetsAttackButtonNotLock` обновлены под новый формат метки (имя теперь
  часть текста кнопки) — контракт на присутствие/отсутствие подстрок сохранён, добавлена
  проверка имени. Новые тесты: `testShownIdsCoverOnlyRenderedNeighborsNotAllCandidates`
  (123 соседа, `max_listed=12` — `shown_ids` содержит ровно 12 показанных id, не все 123) и
  `testButtonLabelTruncatesLongNameAndKeepsPackingIntact` (короткое/длинное имя рядом —
  обрезка, многоточие, различимость меток, ряд не рассыпается на одиночки).
- Tips/guide-вердикт: **нет** — это фикс уже существующего экрана обнаружения (та же
  оценка, что и в `-07`), новой player-поверхности не появляется.
- PHPUnit не рендерит Telegram-клавиатуру: реальный вид кнопок (перенос длинного текста,
  тап по кнопке с именем) — Tier-3 на testbot'е, не этим тестом.

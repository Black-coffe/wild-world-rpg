# Три хода защитника: укрыться, убежать, ударить первым

## Goal

После story у защитника, поднявшего тревогу, есть реальные ходы. «🛡 Укрыться» — новое действие:
остаться, немедленно отдать инициативу и получить надбавку к снижению урона; окно закрывается как
`held`. «🏃 Убежать» — существующий побег, который теперь ещё и закрывает окно как `fled` и сообщает
нападавшему, что цель ушла. «⚔️ Ударить первым» ведёт на существующий `attackPlayer_` и обслуживается
story `-08`. Молчание остаётся правом: ничего не нажав, защитник просто доживает окно.

## Non-goals
- Не менять саму механику побега: прыжок 10–50 клеток, 1000 золота, −50 % HP, −90 % выносливости остаются как есть; добавляется только закрытие окна.
- Не делать «укрыться» неуязвимостью на время: это кнопка «остаться и отдать инициативу», а не безопасная комната.
- Не трогать `AttackPlayerAction` — соседняя story `-08` той же волны держит этот файл. Третий ход защитника («⚔️ Ударить первым») поэтому живёт не здесь: кнопку рисует `-06`, путь до боя закрывает `-08`. Эта story отвечает за два хода из трёх, и её название перечисляет все три только потому, что игрок видит их одним экраном.
- Не вводить новых полей в бой: надбавка едет существующим `damage_reduction` и применяется в `-08`.
- Не заводить свою проверку «окно ещё живо»: только `PvpStandoffService` из `-06`.
- Не запускать полный набор и не делать `DROP`/`migrate` на общей локальной тест-БД; не делать `git stash`/`git checkout`.

## Acceptance criteria
- [ ] «🛡 Укрыться» закрывает окно как `held` через `close()`; атакующий немедленно разморожен и получает сообщение, что цель приготовилась к бою. Надбавка к снижению урона выдаётся не сразу в цифрах, а отражена в статусе окна — считает её `-08`.
- [ ] Побег при живом окне закрывает его как `fled`; нападавший получает сообщение «цель ушла», а его следующий тап всё равно отбивается проверкой смежности, потому что цели рядом больше нет.
- [ ] Побег вне окна работает ровно как сегодня — регресс закрыт тестом.
- [ ] Второй ход защитника (двойной тап, «убежал» и «укрылся» подряд) даёт ровно один применённый переход; второму игрок получает внятное «ты уже отреагировал», а не ошибку и не второй побег с повторным списанием золота.
- [ ] Ход по чужому или истёкшему окну отклоняется объяснением, а не исключением.
- [ ] Сообщения — HTML, экранированные имена, самодостаточный текст без фото, кнопки по 2–3 в ряд; текст тревоги объясняет механику целиком (что происходит, сколько осталось, что делает каждая кнопка) — это и есть just-in-time-обучение по ONBOARDING-coverage, отдельного шага в обучающем потоке спека не заводит.
- [ ] Каждый ход пишет строку аудита кодом из `## Contracts`.
- [ ] Тест строит схему из настоящих классов миграций и покрывает: `held`, `fled`, двойной тап, чужое окно, побег без окна.
- [ ] В `## Implementation notes` сказано: кнопки и их поток PHPUnit не проверяет — только Tier-3 двумя аккаунтами.

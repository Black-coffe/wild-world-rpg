## 3. Отвергнуто и почему

- Ночной OOM / swap / logrotate (T0.5 infra) — swap 4 ГБ уже есть, MySQL 46 суток без перезапуска.
- Индекс `map(x,y)` как дыра прода (T0.1) — индекс есть; остаётся только расхождение миграций (в B10).
- `characters(cell_number)` — 762 строки.
- Set-based UPDATE регена (часть T0.2) — потеряет уведомления о новом уровне.
- Redis сейчас (T0.3) — проблему решает перенос кулдаунов в БД; Redis потребует отменить ADR-024.
- Расширения V2 сверх ADR-137 — L300, снятие потолка `base+40`, трофеи с PvP-эффектом.
- Включение `tribute`, `weight_cap`, `require_tower` при 19 WAU — наказания без аудитории (2/3).
- Тезис «`max_level_gap` отсекает ветеранов» — неверен по направлению.

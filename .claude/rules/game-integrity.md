# Целостность игры — классы дефектов

Строки «Проверка: `php scripts/defects-*-check.php`» ниже работают ручной командой и идут в наборе PHPUnit:
`tests/unit/Defects/` (часть unit2), живой прогон `task-result-foreign` — `tests/database/DefectTaskResultForeignCheckTest.php` (db3).

Перенесено из `docs/defects/` (цитаты владельца и разбор — в карточках).

**Повтор подтверждения необратимого** (`confirm-repeats-irreversible`). Защита от гонки ≠ защита от повтора.
Подтверждение несёт отпечаток того, что игрок видел в превью (хэш плана); исполнение сверяет его с состоянием
под блокировкой в той же транзакции. `ResourceTradeService::bulkSellResources()` — только с токеном. Повтор
отвечает «уже выполнено / запас изменился». Проверка: `php scripts/defects-confirm-once-check.php`.

**Фикс эксплойта и добытое** (`exploit-fix-leaves-proceeds`). В том же плане решить судьбу уже добытого
(запасы, золото, предметы, склад базы, крафт), а не «после выкатки». Двухфазный откат: изъятие до выкатки,
дельта за окно сразу после; расчёт по `action_log` с бэкапом строк и цифрами владельцу.

**Исход дуэли решает бой** (`duel-outcome-not-decided-by-fight`). Дуэль — одна площадка, дистанция не режет урон;
HP подбирается расчётом урона за потолок раундов (нокаут у двух безоружных новичков); баланс судится кривой
«шанс победы от перевеса»; первый удар — жребий, тест держит 47–53 %. «−0 · осталось 1000 HP» — не косметика.
Проверка: `php scripts/defects-duel-knockout-check.php`.

**Запись видна шире участников** (`record-exposed-beyond-participants`). Новый тип записи в существующую таблицу —
пройти всех её читателей (публичные страницы, списки, API, админка). Публичный эндпоинт «по id» несёт тот же
фильтр, что публичный список, и одинаковый 404 для «нет» и «не твоё». Приватные поля (координаты) не хранить,
если записи они не нужны. Только участникам — через ядро (`BattleJournalService::isMine`).

**Итог задачи в вебе** (`task-result-foreign-message`). Итог задачи на `/play` не выбирается только по времени:
чужие фоновые сообщения отсекаются по типу, сигнатура сверена с построителем отправителя. Нет итога — нейтральный
экран «✅ … завершена — итог во входящих 🔔». Проверка: `php scripts/defects-task-result-foreign-check.php`.
Корень: при переписывании story потерялось условие выбранного варианта — оговорки варианта переносятся в story.

**Веб-игроки в guard'ах.** Guard на пути уведомлений игроку принимает `VirtualChat::is()`, а не только
`chat_id > 0` — иначе веб-игроки выпадают из хуков (ADR-189).

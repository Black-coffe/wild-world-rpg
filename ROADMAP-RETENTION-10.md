## §0. Главный вывод за один экран

- **D1 ≈ 45% — это топ-10% индустрии.** Первое впечатление РАБОТАЕТ. Проблема НЕ в нём.
- **D7 ≈ 12.5% — для mid-core/RPG плохо** (норма 20%+; <10% = «сломано ядро, трафик не спасёт»). Killer = **обвал D1→D7** + **стена L1** (87% застряли на L1).
- **Корень — НЕ мета-слой.** Подсказки/нуджи/comeback/стрики/дейлики уже построены (~95%) и LIVE — воронка почти не сдвинулась. Значит лечить надо **ЯДРО первой сессии + причину возврата**, а не добавлять обёртку.
- **Слабое звено = Early (стена L1→L2).** Пустота Middle/Late — симптом (туда никто не доходит), не болезнь.
- **Дисциплина «audit-first»:** ~70% того, что хочется «построить», **уже построено и спит за killswitch** (fast-start, soft-start, скриптовая встреча, NPC-march, sport-дуэли). Поэтому **Сессия 1 — диагностический шлюз**, а не стройка.

## §0.1. РЕЗУЛЬТАТ S1 (выполнена 2026-06-24, прод read-only) — премиз скорректирован

> Полные данные: [[srez-S1-retention-diagnostic-2026-06-24]] (vault). Кратко:

1. **Премиз был СТЕЙЛ — почти всё «спящее» УЖЕ LIVE на проде** (флипнуто через admin UI; seed-дефолт вводил в заблуждение): fast-start, soft-start (`gather.early_access`), lucky-find, starter-kit, quest-chain, auto-escalation, npc.interaction/march, daily-tasks, все returnability, level/boon-tier, **pvp.duel+ladder**. **Genuinely OFF (core):** только `npc.newbie_zone.population=0` (ghost-town), `quests.branching` (мёртв), node-announce. → **«Дешёвая активация» исчезает: флипать нечего, всё включено — а D7 плохой и 86% на L1 ⇒ проблема СТРУКТУРНАЯ.**
2. **«Туристы vs проваленные» = ОБА ~50/50.** Из 468 L1: **~56% (263) ничего не сделали** (туристы — installed→стена текста→ушли; 49% даже не назвали чара), **~44% (205) реально вовлеклись, но застряли** (204 двигались; **69 исследовали 100+ клеток**, живы из вовлечённых ~29-46).
3. **🔴 Левелинг-стена ДОКАЗАНА:** 69 L1-чаров с 100+ клетками (макс **1008**) имеют **avg level-sum 0.905** при нужных 8.0; agility **отрицательная** (смерти эродируют статы). Прошёл 1000 клеток — всё ещё L1.
4. **Честный baseline (n=173): D1 24.3% / D7 15.6%** (срез-06-20 D1 45%/D7 12.5% был узкой n=40-когортой). **Доминирующая утечка = немедленный bounce** (~76% не вернулись к D1; 56% не двигаются), не распад день2-7.
5. **PvP duels/ladder: 0 строк ladder = BUILT-ACTIVATED-BUT-DEAD.** Аудитории нет → PvP-арена снимается.

**Корректировки плана (ниже учтены в §4):** S2 переориентирована «активация→населить ghost-town + почему живое не работает»; **S4 cold-open поднят к ТОП-приоритету наравне с S3** (половина потерь = pre-engagement bounce); S9 PvP-райдер снят; baseline S10 = D1 24%/D7 16% + bounce/named-rate. **S3 (левелинг) подтверждён #1 структурным фиксом.**

5. **🚀 LIVE НА ПРОДЕ DORMANT — `v0.51.491`** (коммит `673962ab`; PHPUnit/Deploy/site ✅; прод read-only: 6 ключей, enabled=0). **Tier-3 на testbot PASS** (автономный webhook+SQL, чар 491→L1): рычаг B exp/str ×2.0 + C tired ×0.80 + D прерывание (новичок 0 потерь vs легаси −0.5/−0.25) — точны вживую; OFF=byte-identical подтверждён; A (gather) юнит+интеграция-proven.

## §2. Диагноз воронки (корневые причины, code-grounded)

> Все факты сверены редколлегией-engineering против `develop`. Где число поправлено критиком — указано.

1. **🔴 Математика L1→L2 — главная стена.** `Level = floor((exp+str+agi+int)/4)`, пересчёт **каждую минуту** (`HealthRegenerationHandler.php:128`). Новичок=0.04; L2 нужна сумма ≥8.0. **Добыча даёт 0 опыта** (`GatherResultPersister.php:97`) и лишь ~0.0008 стата/ресурс (≈ничто). Ход=**+0.03** к сумме (`MoveCharacterToDirectionAction.php:228`), крафт=**0 XP** (только статы). → **сотни действий до L2** (~265 ходов) против бюджета **~29 ходов/сессию** (3.35 устал./ход, реген +0.1/мин до L20). Математически гарантирует 87% на L1.
   - **⚠️ Поправка критика (важно):** мой черновик утверждал, что Верстак L4 / Склад L6 / Теплица L8 невидимы новичку — **ЛОЖЬ**: все три `level_required => 1`. Реальная стена первой постройки = **стоимость ресурсов + время стройки**, не уровень. Реальные level-гейты: **фракция L10**, Gym/Lab L5, Robotics L10, Teleport L12, Arsenal L15. → стену L1→L2 чинить ради «видимого прогресса + дойти до фракции L10 + ощущение анлока», а ресурс/время-стену — отдельно (Сессии 4-5).
2. **🔴 Мёртвые async-таймеры сессии-1.** Первая реальная добыча ≥10 мин (есть спящий fast-start 2 мин), первое здание HandPump (единственный быстро-доступный)=60 мин, первый верстак 100-140 мин; worker тикает раз/мин. **54% заканчивают первую сессию с пустым инвентарём.**
3. **🔴 Пустой/одиночный мир.** Стартовая зона = NPC-призрак (~21 NPC на Y≥900 vs 1999 севернее); скриптовая первая встреча и march-встречи **построены, но спят**; 0 ощущения мультиплеера → **MMO ощущается одиночной** (предаёт портрет П6).
4. **🟠 Нет дофамина первой постройки.** Build = **#1 измеренная утечка (9%)**: захватил базу, открыл — и СТОП.
5. **🟠 Первый крафт теряет 2/3 (33% conv).** Пустой инвентарь не даёт скрафтить; крафт не ощущается стоящим.
6. **🟠 Холодный старт Move 43% не двигаются.** Move не на постоянной клавиатуре `[Перс·База·Крафт·Карта]`; награды за ход не видно; ход в пустой туман за 3.35 устал.
7. **🟡 Простыня /start (~250 слов) + 7-экранный туториал → «обрыв» на реальные таймеры.**
8. **🟡 Нет соц/реферальных крючков.** Реферальной системы **НЕТ** (подтверждено: только SEO-атрибуция `acquisition_source`; deep-link payload-инфра есть). PvP дуэли/арена/ладдер спят/мертвы.

**⚠️ Честная рамка по приобретению (объекция devil's-advocate, принята):** интейк упал до ~2 рег/2 дня; ~857/1066 заблокировали бота (≈80% мёртвый инсталл-бэйз). Поэтому: (а) спринт идёт **ПАРАЛЛЕЛЬНО** SEO-потоку (чиним «дырявое ведро», пока поток наполняется — отдельный трек, не входит сюда); (б) успех меряем **rate-метриками (D7, L2-rate, шаги воронки), не абсолютным числом удержанных**; (в) при низком n замеры R-среза дают тренд, не приговор. **И главное — Сессия 1 ОБЯЗАНА проверить: 87%-на-L1 — это проваленные игроки или мёртвые туристы** (сегментация по intent). Если в осн. туристы — спринт пере-приоритизируется на acquisition-quality.

### S2. Населить ghost-town + диагностика «почему живое не работает» (ПЕРЕОРИЕНТИРОВАНА после S1)

- **Зависимости:** S2-S5 (нужно живое ядро сессии-1, чтобы было что «продолжить завтра»).

### S7. Живой остров — честно: накопительные следы реальных игроков (НЕ фейковый онлайн)

Отдельная `referrals`-таблица (если будет) → классифицировать.

- **Зависимости:** **S3** (qualify L3 требует достижимого L3 — реальная зависимость).

### S9. Ранняя выживальческая атмосфера + (опц.) активация sport-арены
- **Цель:** доставить выживальческую фантазию раньше, чем таймеры наскучат (служит П1/П3 рано; П4-lite).
- **Проблема:** фантазия заявлена, не доставлена; первый час = tap/wait; события нацелены на mid/late.
- **Что:** телеграфированная **несмертельная** опасность в первой сессии (далёкая буря, «выносливость на исходе — найди воду», шорох с **выбором**); выборные микро-события (реюз движка событий + ADR-089), нацеленные на новичков. **⚠️ PvP-райдер СНЯТ после S1:** sport-дуэли/ладдер УЖЕ LIVE и МЁРТВЫ (`pvp_ladder`=0, 3 открытых дуэлянта) = BUILT-ACTIVATED-BUT-DEAD — нет аудитории, PvP-discoverability не в этом спринте. **Лидерборды — НЕ сейчас** (на ~47 активных «ты #1 из 3» демотивирует).
- **Класс:** 🔴 §4.6 соблюсти (cap урона события ~10% HP — уже есть); 🟡 §6.3 новые события. **Killswitch/GS:** `world.events.newbie_atmosphere.*`; (sport-дуэли — существующий `pvp.duel.enabled`). **WipeManifest:** н/п. **Onb/Guide/Tips:** hint + guide + tip-вердикт; новые события → Image-contract или media-off текст.
- **Smoke:** Tier-3 + media-off проверка; (sport-арена — живой роут на testbot, урок E25: scp кода до тапа).
- **Метрика:** session-1 «вау»-плотность (качественно); участие в арене (если активирована).
- **Зависимости:** S2-S5 (атмосфера поверх работающего ядра).

### S10. Срез + тюнинг + консолидированный анонс «Новая заря»
- **Цель:** данные решают; игроки получают ОДНУ волну улучшений.
- **Проблема:** проект слепнет без среза; анонсы нельзя по ходу.
- **Что:** повторный когортный срез (методика S1): D1/D7, L2-rate, шаги воронки Move/Craft/Build, реферал-адопшен, vs baseline 06-20 — **с честными confidence-оговорками на малом n**; тюнинг всех GameSettings из S2-S9; фикс-лист микро-UX; **консолидированный broadcast «Новая заря»** живым игрокам (честно «как добраться»; БЕЗ обещаний спящего); решения по killswitch-активациям.
- **Класс:** 🟢 (read-only + анонс-дисциплина §анонс-в-конце). **Smoke:** read-only prod SQL; Tier-3 финальный.
- **Метрика:** полная дельта воронки/ретеншна vs **S1-baseline (n=173): D1 24.3% / D7 15.6%** + вторичные (bounce-rate 56% не двигаются, named-rate 42%, L2-rate свежей когорты 14%). **Спринт-цели: D7 → 20%; bounce-rate ↓ (named-rate 42% → ≥65%); L2-rate 14% → ≥35%.**
- **Зависимости:** S1-S9.

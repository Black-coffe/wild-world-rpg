Компонентная база публичного сайта Wild World. Стилистика «найденной фотоплёнки»: уголь, ржавчина, янтарный фонарь, едва заметное зерно. Кириллица — Oswald для табличек и заголовков, Manrope — тело, JetBrains Mono — цифры и логи. Все компоненты функциональные, без фреймворков.

К компонентам → Открыть Адаптив-лабораторию
Платформа — Web (Telegram WebApp, CI4) Целевые экраны — 360–1920 Шрифты — Oswald · Manrope · JetBrains Mono Палитра — Metro «Найденная фотоплёнка»

Каждый виджет здесь — кандидат в реальный модуль сайта.

Картинка — только усиление: текст обязан нести смысл сам, как требует конституция media-off.

Анимации — короткие (140–420 ms), без «надувания» — игрок зашёл не на парад, а за делом.

Кнопки — стенсиль, цифры — моно, цитаты — italic. Tone of voice — холодный, прямой, с лёгкой пылью.

CTA-перебивка — внутристатейная (long-read)

Узнаваемый акцентный разделитель для длинных статей блога. Flat (0 радиусов/теней), CSS-микроанимация: диагональная «опасная» лента + мягкий sweep + hover-блик по кнопке. Уважает prefers-reduced-motion. Вставляется в content_html внутри .prose, кнопка ведёт прямо в бот.
